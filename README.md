# yandex-tts

TTS-демон и CLI для Яндекс Станции на Rust: демон держит соединение со Станцией и синтезирует речь, CLI отправляет ему команды через Unix-сокет. Устанавливается как systemd user-сервис.

## Установка (release, по умолчанию)

Linux x86_64/aarch64. Скрипт скачивает последний GitHub-release, проверяет SHA256, ставит бинарники `yandex-ttsd`, `yandex-tts`, алиас `tts` в `~/.local/bin`, устанавливает systemd user unit и запускает сервис. Обновление транзакционное: при сбое полный откат к предыдущему состоянию.

```bash
curl -fsSL https://raw.githubusercontent.com/MrUndead1996/yandex_tts_cli/main/install.sh | bash -s --
```

или из клона репозитория:

```bash
./install.sh
```

Своя директория для бинарников (ExecStart в unit переписывается на выбранный путь):

```bash
./install.sh --install-dir /opt/tts/bin
```

Дополнительные опции: `--build-from-source`, `--force` и `--help` — подробная справка.

## Установка навыка OpenClaw (отдельная команда, офлайн)

Навык устанавливает сам CLI: файлы навыка встроены в бинарник, поэтому команда работает офлайн и не меняет сервис:

```bash
tts skill_install ~/.openclaw/skills
```

Если бинарник установлен не в `PATH`, вызовите его по полному пути, например `/var/docker/openclaw/tools/tts skill_install ~/.openclaw/skills`.

## Конфигурация (обязательна)

Файл `~/.config/yandex-stationd/.env` (режим 0600). При первом запуске он создаётся из `.env.example`; заполните переменные и повторите установку:

- `YANDEX_X_TOKEN`
- `YANDEX_MUSIC_CLIENT_ID`
- `YANDEX_MUSIC_CLIENT_SECRET`

Значения вводятся только в файл, не в командную строку. Префикс `export` не поддерживается systemd `EnvironmentFile`. Существующий файл никогда не перезаписывается (только chmod 600). Конфиг валидируется перед установкой и любым изменением сервиса.

## Команды CLI

```bash
yandex-tts say "Привет"    # синтезировать и проиграть речь (через демон)
yandex-tts ping            # проверить доступность демона
yandex-tts --version       # версия
tts skill_install <PATH>   # установить навык OpenClaw в корень навыков (офлайн)
```

Если Алиса на Станции находится в состоянии `SPEAKING`, новые `say` отклоняются с ошибкой `station_speaking`. Одновременные запросы `say` также отклоняются, пока предыдущий ожидает ответа Станции. После смены состояния Алисы команды снова принимаются.

Логи демона: `journalctl --user -u yandex-ttsd.service`.

## Сборка из исходников

Только явным opt-in, релиз скачивается по умолчанию. Перед клонированием/сборкой запрашивается интерактивное подтверждение; подтверждение автоматически не срабатывает в неинтерактивной среде — для скриптов/CI нужен `--force`. Автоматического fallback на сборку при ошибке скачивания нет. Конфиг валидируется до сборки.

```bash
./install.sh --build-from-source          # спросит подтверждение
./install.sh --build-from-source --force  # без подтверждения (CI)
```
